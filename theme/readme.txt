A fast, clean block theme designed entirely from the Site Editor.

== Description ==

Pergel is the presentation layer of the Pergel system. Colours, type, spacing,
templates and patterns are edited in Appearance > Editor. Blocks, SEO and AI
layers, WooCommerce features and content types come from the companion
Pergel Engine plugin, so changing the theme never loses content.
